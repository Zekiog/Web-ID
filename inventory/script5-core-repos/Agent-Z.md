# Agent-Z — orchestration brain for self-hosted AI agents

Agent-Z is a Python-based orchestration "brain" for a self-hosted AI agent content platform (internal MVP). The repository contains the CLI entrypoint, the Brain orchestrator, pipeline steps, publishers, workspace isolation, autonomy policy layer and supporting utilities.

Status
- Active development (internal). See docs/PROJECT_STATUS_REPORT_2026-06-22.md for the latest autogenerated status report.

Quickstart (developer)

1. Create a Python 3.11+ virtualenv and install deps:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -e '.[dev]'
```

2. Configure a workspace and environment (example):

```bash
cp .env.example .env
# Edit .env to set internal API secret, memory_core_url, vizion_base_url, etc.
export AGENT_Z_WORKSPACE=default
```

3. Run the CLI compose command (example):

```bash
echo '{"intent": {"topic": "example"}}' | agent-z --workspace default compose
```

4. Run the status server locally:

```bash
agent-z status
# then visit http://127.0.0.1:8091/webhook/fleet-status
```
